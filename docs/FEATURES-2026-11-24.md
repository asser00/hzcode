## Fixes for the reported issues
1. **World-join crash (Feature placement NPE)**: `HordeCampPiece` left `mirror`/`rotation` null
   (private fields of StructurePiece, only set via NBT ctor) -> `placeBlock` NPE'd on fences.
   Fixed with `setOrientation(Direction.NORTH)` (sets mirror/rotation to NONE).
   Also the structure JSON needed the required `spawn_overrides` key (1.20.1 codec) - added.
   (FancyMenu was NOT the cause - it only appears in crash footers.)
2. **Render / skins**: skin pools are now resolved through the client `ResourceManager`
   (`listResources("textures/entity/skins/<type>")`) instead of classpath probing, so mod-jar
   textures always load; render type stays `entityCutoutNoCull` (never see-through). Pools are
   **curated per creature** and include the player's own downloads from
   `E:\Games\Minecraft\instances\*.png`:
   - zombie <- `scanv.png` + original zombie.png + rottencreatures zombie_lackey + 2 internet skins
     (no more blue quark ocean/beach zombie variants)
   - soldier <- `solder.png` + `medic .png` + superbwarfare armory + chovys apocalypsetrader + 2 internet
   - scavenger <- `scaven.png` + MCA outlaw/adventurer/cultist + 4 internet skins
   - terrorist <- `trerror.png` + MCA guard/archer + extinction trader + 4 internet skins
   Skin per entity is deterministic from its UUID (`SkinVariant.index`).
3. **Guns**: exact TACZ rifle list (from `data/tacz/index/guns/*` type field) for soldiers
   (random rifle + matched ammo via `IAmmo.isAmmoOfGun`); terrorists get any random TACZ gun;
   scavengers get a random melee weapon; soldiers/terrorists fall back to a random melee weapon if
   TACZ is unavailable, and soldiers also have a `MeleeAttackGoal` fallback. No more unarmed soldiers.
4. **Taming (wolf-like)**: hold **Taming Treat** (`horde_soldiers:taming_treat`, in the creative tab)
   and right-click a soldier/scavenger -> chance `taming.chance` (0.5) per use, hearts/smoke feedback,
   action-bar hint when holding the wrong item. Tamed: leaves horde, persisted owner in NBT, never
   despawns, follows + defends you; sneak + empty hand releases. Faction system treats tamed mobs as
   ALLIED with the owner.
5. **Trading**: right-click a soldier/scavenger with a trade good (`trading.giveItems`: bread,
   cooked_beef, apple, iron/gold ingot) -> consumes 1, gives a random reward (`trading.receiveItems`:
   arrows, torches, food, materials, TACZ ammo, rare golden apple), 1s cooldown, villager-yes sound.

## Natural spawning
All 4 types spawn naturally in the overworld (`forge:add_spawns` biome modifiers + ON_GROUND
placements registered in common setup; zombies use vanilla monster darkness rules). Per-type toggle:
`<type>.naturalSpawn` in config. Spawn eggs and `/horde spawn` always work.
