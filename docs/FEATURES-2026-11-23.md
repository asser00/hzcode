# New features - 2026-11-23 - horde_soldiers 2.0.1 (feature build)

All requested features are implemented, built, and boot-verified in `Apocalypssia-4.94`
(0 FATAL, no crash reports, title screen reached, mod listed in `logs\modlist.txt`).

## 1. Skins for everyone
- Every entity type now has a **skin pool**: `assets/horde_soldiers/textures/entity/skins/<type>/0..N.png`
  (zombie 8, soldier 7, scavenger 7, terrorist 7 - all verified 64x64 PNGs).
- Sources: **16 real player skins downloaded from the internet** (visage/Mojang accounts:
  Notch, Steve, Alex, Herobrine, Technoblade, Dream, Philza, TommyInnit, Sapnap, etc.) **plus
  13 textures taken from mods already in the modpack** (superbwarfare `armory` villager skin,
  MCA `outlaw`/`adventurer`/`cultist`/`guard`/`archer`, chovys apocalypse `apocalypsetrader`,
  ae2 `fluix_researcher`, extinction trader, quark zombie-villager ocean/beach,
  rottencreatures `zombie_lackey`, so_many_enchants enchanter).
- Each entity picks its skin **deterministically from its UUID** (`SkinVariant.index`), so a mob
  keeps the same skin forever. Renderers: `ClientModEvents` (zombie/soldier/scavenger/terrorist
  all use pools now).

## 2. Random weapons
- **Scavengers**: spawn with a random **melee weapon** in hand - swords/axes/tridents plus any
  registered modded item whose id looks melee-like (katana, machete, ...) and has attack damage
  (`WeaponStocker.randomMelee`, prefers swords/axes). Config: `scavenger.randomMeleeWeapons`.
- **Soldiers**: each gets a random **rifle-class TACZ gun** (`WeaponStocker.randomTaczGun(riflesOnly=true)`
  over the rifle id set: ak47, ak12, ak74m, m4a1, m16a4, aug, g36k, hk416d, fn_fal, mk14, ...)
  with **matching ammo found via TACZ `IAmmo.isAmmoOfGun`** and loaded rounds. Config:
  `soldier.randomWeapons` (falls back to `soldier.soldierGun`/`soldierAmmo` when off or no TACZ).
- **Terrorists**: same, but any gun class (rifle/smg/pistol/shotgun/sniper). Config:
  `terrorist.randomWeapons` + existing `terroristsUseGuns`.

## 3. Taming (soldiers + scavengers)
- Right-click a soldier/scavenger with the tame item (**default `minecraft:cooked_beef`**) to
  attempt a tame; chance per item default `0.34` (config `taming.enabled` / `taming.item` /
  `taming.chance`).
- On success: hearts particles, the mob **leaves its horde**, is persisted as yours in NBT
  (`Owner` UUID), never despawns, **follows you** (`TamedFollowGoal`) and **defends you**
  (`TamedOwnerDefenseGoal` - attacks whoever last hurt you). The faction system treats tamed
  mobs as ALLIED with their owner and the owner's other tamed mobs (`FactionManager.tamedRelation`),
  so nothing of yours attacks them.
- **Release**: sneak + empty hand while owning it.
- Handler: `ModEvents.onEntityInteract` (PlayerInteractEvent.EntityInteract, server side).

## 4. Normal (natural) spawning for everyone
- `ModSpawnPlacements` registers `ON_GROUND`/`MOTION_BLOCKING_NO_LEAVES` placements for all four
  types during common setup. Zombies use vanilla monster rules (darkness); humanoids require
  solid ground, no fluid, and pass `Mob.checkMobSpawnRules`.
- Biome modifiers `data/horde_soldiers/worldgen/biome_modifier/add_<type>_spawns.json`
  (`forge:add_spawns`, overworld) give weights/group sizes: zombie 100 (2-5), scavenger 50 (1-4),
  soldier 30 (1-3), terrorist 25 (1-3).
- Per-type toggle at spawn-check time: `zombie.naturalSpawn`, `soldier.naturalSpawn`,
  `scavenger.naturalSpawn`, `terrorist.naturalSpawn` (all default true). Spawn eggs and
  `/horde spawn` always work regardless.

## 5. Structure: horde camp
- Code-registered structure `horde_soldiers:horde_camp` (`structure/ModStructures`,
  `HordeCampStructure`, `HordeCampPiece`): 9x9 plank/cobble platform, 4 corner fence posts,
  torch, lit campfire, loot chest + sometimes a barrel (`loot_tables/chests/horde_camp.json`:
  food, iron, leather, arrows, torches, TACZ ammo, name tag, golden apple).
- Data pack: `worldgen/structure/horde_camp.json` (overworld, surface_structures) +
  `worldgen/structure_set/horde_camp.json` (random_spread spacing 28 / separation 10 / salt 90917).
- Find it in-game: `/locate structure horde_soldiers:horde_camp`.
